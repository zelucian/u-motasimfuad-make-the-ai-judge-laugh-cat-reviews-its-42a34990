A one-star review written by a house cat about its human, for the make.fun competition "Make the AI Judge Laugh: Cat Reviews Its Human". It keeps the deadpan shape of a real review while the complaint goes somewhere only a cat would go.

> One star. He closes the bathroom door like I don't pay the mortgage in hair. I have seen the mortgage. It is hair.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the review as a single line to `out/entry.txt`.
